1. A special skill, 'Stance Shift', which changes the spear stance, has been added.
- It is automatically learned upon completing the 3rd Class Transfer.
- Depending on the spear stance, it is divided into 'Swing Mode' and 'Pierce Mode', and the mode can be switched by using the skill.
